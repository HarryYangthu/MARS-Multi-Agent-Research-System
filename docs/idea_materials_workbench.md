# Idea 工作区的研究材料

Idea Agent 的“任务处理记录”页面直接提供“研究资料与上下文”：

- 论文：获取状态、采用/排除/暂缓的理由、迁移思路、来源链接、实际阅读范围。
- PDF：从本次运行的本地归档打开，支持逐页阅读和打开/保存原文件。阅读器与 worker 随前端打包，不使用外部在线预览服务。
- 调研结论：来自最新版方案中的 research_context，展示选择原则、方法、取舍、限制、停止依据和待核验问题。
- 检索记录：展示实际工具查询及返回结果；没有正文阅读记录的检索命中不标为已读。
- 背景和代码：展示本次任务的公共知识快照、研究任务、上下文编译记录以及工具实际返回的代码片段。部分读取会显示字符范围，不用当前工作区文件替代历史内容。

运行期间自动刷新；完成后可手动刷新。旧任务也能根据保存的记录展示材料，不需要再次生成方案。

## 失败诊断

`search.fetch_sources` 的失败摘要包含论文名称、错误码与具体原因。历史通用错误可以根据完全匹配的工具调用记录补充说明，原始记录保持不变。404 表示当前下载地址没有返回文件；403 表示该入口拒绝访问。一个来源获取失败不等于整次调研失败，论文取舍及证据是否充分仍需分别核验。

原文件下载通过 source_id 查找归档，并核对路径边界与 SHA256。阅读失败但已完成归档的文件仍可供用户复查。正文预览接口只接受材料 ID，不接受任意文件路径；材料列表不携带完整背景或代码正文，点击后再加载。越界、缺失、过大或损坏的材料明确提示。

## 实现和验证

- 后端：`api/idea_materials.py` 聚合保存的材料，`api/artifacts.py` 提供材料列表和正文接口。
- 前端：`IdeaRunMaterials.tsx` 展示材料，`ResearchPdfPreview.tsx` 按需加载 PDF.js，避免原生内嵌 PDF 在部分浏览器中空白。
- 新增依赖：`pdfjs-dist`，用于本地 PDF 逐页绘制，不改变 Agent 调研或模型调用。
- 单元验证覆盖：空任务、完整背景与部分代码、快照校验、404、重复阅读、缺失归档、越界文件、损坏/过大材料、不安全链接、方案版本选择与历史错误说明。
- 实际页面验证使用已有真实 Idea 运行归档，包括论文页面与翻页、背景全文、代码片段和调研结论；不把 UI 验证当作新模型运行或方案收益验证。
