## 方案与剩余缺陷

候选方案：16×16 双线性 LUT（256 个实参数）替换为 12×12 三次张量积 B 样条控制点，加两轴 18 个节点参数，共 162 个实参数。0.633 参数比仅为符号账本；没有测得表达能力或 PIMC 性能提升。

修稿后的结构校验通过，但仍存在：负实增益被错误描述为不改变相位；G=5、M=12 的消融不符合节点向量长度关系；归一化后最小间距保证前后矛盾；初始化仍把控制点采样等同于投影；C² 光滑性被过度用作优越性依据。这说明现有校验能检查格式和部分材料一致性，不能代替方法正确性审查。
