1. `search.arxiv_search` 增加 `arxiv_ids` 元数据查询，可指定真实论文的 `vN` 版本，拒绝与关键词/过滤/排序模式混用。精确请求会核对论文和显式版本，归档原 XML 与哈希；缓存重新解析 XML 并逐项核对元数据。关键词检索仍负责发现未知论文，这个入口不负责选择研究答案。
2. 原生文档提交先严格解析原始参数，JSON 错误位置对应模型实际提交的行列。重复键、非有限值与非法顶层字段仍拒绝；没有修补原始参数或偷偷执行候选。
3. 引句匹配增加受限的真实 PDF 行末断词兼容。只有原页确实存在符合条件的单个换行连字符时才允许省略；不能跨空段、删除行内连字符或改数学符号。原引句与收据不改写，匹配记录保留原页位置、模式和省略位置，后续审查仍读取真实原文窗口。
4. 子任务异常保留委派身份、运行错误、失败类型与可用 checkpoint，失败来源只能作为恢复线索，不计为接受覆盖数。主 Agent 按成功报告计算尚缺论文；研究提示与 Reflection 另外强调区分背景基线、作者方法及尚未实际看到的方法段。
5. 正式 Idea、研究子任务与真实验证场景将输入预算从 96,000 调到 256,000；通用策略允许范围仍有限，为 4,000–512,000。估算器使用 UTF-8 字节上界，不是 provider 的实际 token 计数。[DeepSeek 官方说明](https://api-docs.deepseek.com/quick_start/pricing/)列出 Flash/Pro 的 1M context，新的显式预算仍低于该值。预算属于配置指纹，旧运行不能据此重置或扩大额度。
