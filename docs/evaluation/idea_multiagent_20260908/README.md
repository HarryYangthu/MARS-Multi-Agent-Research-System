| 模型提出的方向 | 参数量（G=16） | 模型给出的用途 | 审阅结论 |
|---|---:|---|---|
| 主方案：自由网格 + 双线性插值 | 286 | 让控制点位置适应局部曲率 | 存在可研究的机制，但方法定义未通过审查 |

原文的 `human_summary`：

> 将 PIMC 非线性层的 2D LUT 从固定均匀网格+最近邻读取改为可学习自由网格（累积差量参数化）+双线性插值读取，使控制点数量不变而节位可自适应移动，从而在不显著增加参数的前提下提升非线性表达能力。

这句话中的收益是模型假设，不是实测结论。其主方案从 256 增加到 286 个实数参数，增加 11.71875%；1.2 倍上限和 RMSE 至少降低 5% 都是本测试中的定义，不是用户已确认的业务目标。

| 质量维度 | 本次直接检查到的事实 |
|---|---|
| 参数账本 | G=10、16、32 三种声明规模的主方案计数正确，分别 118/100、286/256、1086/1024 |
| 边界定义 | 内部网格点同时落入两个闭区间，“唯一单元”不成立；需要明确选边约定 |
| 网格移动指标 | 所有原始间距放大两倍，归一化实际网格不变，但原文指标从 0 变为 1 |
| 消融训练 | 最近邻选择不变时，输出对节点位置局部不变；有限差分为 0，不能据此宣称普通反传能移动节点 |
| 数值实现 | 实数下 softplus 严格为正，不代表浮点实现始终正；极端有限负输入可下溢为 0 |
| 方案多样性 | 备选集中在网格和插值组合，尚不能证明进行了充分的跨机制比较 |
| 项目适用性 | 使用符号化最近邻基线，没有真实 PIMC 基线、数据或仿真 |

## 真实多角色组件测试

本轮新增独立测试入口，用公开符号化 LUT 任务运行现有五角色 workflow，逐次归档原始输入、输出、角色、模型配置和消耗。基线明确已经采用双线性插值；总实数参数上限为 256。所有角色只获得任务文本及任务引用，不提供企业数据、历史候选或外部修正答案。

这是角色协作组件测试：不会检索论文，不代表整个研究到下游交接链路，也不会把给定任务引用算作论文证据。这里记录全部尝试，不挑选成功案例。
