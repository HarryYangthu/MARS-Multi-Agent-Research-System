# 新手使用引导

项目起始页及设置页新增“新手使用引导”，地址 `/onboarding`。四步流程：

1. 配置模型服务商、模型、API 地址与 Key。使用现有模型配置 API，将连接应用到当前已启用角色，并保留角色其他参数。Key 不写浏览器存储，保存后清空输入框。已有角色配置可在高级页面单独调整。配置保存与真实模型连接验证分别显示。点击“测试连接”使用当前输入；Key 留空时复用该服务商已保存的密钥。
2. 打开已有代码文件夹，或选择已接入项目。复用真实目录选择和项目注册；不复制研究代码。项目身份写入代码目录 `.mars/`。
3. 上传 UTF-8 Markdown 背景资料到当前项目 `context/`，重新发现文档并提供预览。缺资料允许跳过。上传内容始终作为参考，不因文件名为 AGENTS.md 提升为项目约定。同名文件拒绝覆盖；路径越界、符号链接、非 Markdown、空白、二进制和超限输入拒绝。自定义扫描规则未包含上传路径时撤销此次新文件并明确报错。
4. 查看准备摘要，进入新研究表单。通过项目身份从后端重新读取项目，将代码位置和 reference 背景路径带入；不继承旧目标、预算或虚构命令。仍需填写运行命令、指标和权限。完整研究启动保持阻断。

上传通过 `api → bridge/project_onboarding → harness`，沿用项目文档数量/字符预算与项目上下文快照。服务只创建新背景文件，不覆盖源码或已有资料。

## 模型连接测试（2026-09-28）

“保存 API 配置”旁新增“测试连接”。通过 `api → bridge/model_connection_test → harness/llm` 发送一条真实简短模型请求；不保存表单配置，不启动研究，不发送项目背景。只有收到非空真实响应才显示成功，并显示请求模型和耗时。修改表单后清除旧测试结果。

测试沿用原生 provider 和模型 reasoning 兼容参数。服务端默认 30 秒超时、零自动重试、单进程最多一个测试；前端 40 秒停止等待。具体策略在 `configs/models.yaml` 与 `configs/frontend.yaml`。密钥缺失、鉴权失败、额度/限流、请求拒绝、服务故障与超时有独立提示，异常正文与密钥不返回浏览器。请求体有大小限制，验证错误也不回显输入。

验证：36 项连接/配置/项目引导/模型注册测试通过，包括真实拒绝连接、真实不响应 TCP 连接、并发拒绝、零重试与敏感字段不回显。strict mypy 646 文件、4 条依赖合同、相关 ESLint 和生产构建通过（现有其他页面仍有 lint warnings）。在生产浏览器点击按钮，用已保存的智谱 glm-5.3 配置得到真实成功响应，界面耗时 1.16 秒。测试前后模型配置、角色配置、密钥文件逐字节摘要一致；该测试不代表各研究角色、工具或完整研究执行通过。
