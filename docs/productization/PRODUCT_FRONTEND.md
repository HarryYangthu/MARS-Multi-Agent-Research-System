# 产品前端增量与验收边界

主导航收敛为项目、研究任务、结果、设置。原实验台位于 `/lab`；旧首页的 run/project 链接仍重定向到实验台。高级诊断入口仍保留；这一步没有宣称旧流程已经全部迁移。

- 项目页呈现真实路径与接入状态，创建/读取失败可重试；路径存在不等于训练依赖就绪。
- 任务与结果目录默认列出全部项目的保存记录，可仅筛选当前项目。冻结合同不要求注册全局项目，因此不能只从注册项目列表决定可见记录。
- 新建页可导入 API/CLI 冻结的合同 JSON。服务核对哈希及声明源文件后保存真实任务；执行边界尚未全部接入时明确只读，不发模型请求。
- 任务控制查询后端真实 owner，持久记录损坏或只读时仍可停止已持有工作。未知远程状态不能因此标为已停止；本增量不兑现完整远程停止 SLA。
- 结果页读取实际作业回执和指标，展示有限曲线、描述统计、未知费用与复现前提，下载同源的已校验离线 ZIP。结果页只读不等于运行本身不可变。

请求策略在 `configs/frontend.yaml`，由生产构建编译。新页面与控制请求设置时限，明确 loading、空态、错误、超时；离页/切项目不继续发出后续启动请求。服务器已受理的操作不会因浏览器取消而自动撤销；不确定提交先核对任务记录，不自动重试。

旧创建表单仍有领域数据字段，阶段工作台也尚未完成用户语言和布局收敛。项目向导、模型/SSH 凭据设置、暂停与完整恢复仍待接入。1280×720、1440×900 的局部真实浏览器检查不替代全部页面、高分屏、桌面安装包或五名目标用户的完整旅程验收。

本轮真实浏览器证据包含 CPU 计算结果、无启动合同、下载哈希、断网离线报告，以及 SIGSTOP/SIGCONT 后端触发的实际超时和恢复。测试目录从旧 results 配置升级时真实返回 409，明确作为失败记录保留；只更新了该隔离目录，产品配置迁移仍待完成。
