# 主控托管

研究对话顶部的「主控托管」开关默认关闭。关闭时保留人工审批；开启时由主控模型审核阶段产物、实际仿真配置以及已有诊断建议，决定批准、返工或请求用户接管。新对话独立选择，当前对话和关联任务保存选择。旧的 `auto_mode` 接口字段为兼容保留，其含义改为主控审核；产品创建任务不再设置无条件 `auto_approve`。

主控审核使用 `configs/agents.yaml` 中 Commander 的实际模型和任务共享资源预算。审核输入包括用户目标、冻结的项目规则、当前文档、批准的上游文档、产物检查和真实代码检查记录。文档身份、代码写入记录和配置 token 在批准前复核；模型不能绕过 Schema、基线保护、预算或用户指定的仿真后暂停。返工次数达到上限、缺证据、权限/配置问题和模型失败时交回用户。关闭开关或人工接管会停止尚未完成的主控审核，不撤销已完成的批准。

配置默认值位于应用源码 `configs/commander_review.yaml`。桌面用户数据目录中的同名配置优先；缺少该新文件的既有工作区读取随应用发布的默认值，升级不会覆盖用户已有配置。模型失败不会自动重试，同一组材料不会因页面轮询反复调用模型。

实际输入、逐轮模型请求和回复保存在 `agent_traces/commander/<id>/`。审核理由与状态在 `hitl/managed_reviews/` 和 `hitl/managed_review_state.json`，批准/返工进入原有 `hitl/review_log.jsonl`，仿真配置确认保留原有证据绑定。对话展示真实审核进展；完整 Agent Trace 保留在详情。
