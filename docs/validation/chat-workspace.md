# 研究任务聚合到主对话

用户打开研究任务时，默认进入关联的研究对话。对话内的研究工作区展示各阶段的文档、方案细节、论文调研统计、阅读证据和方法比较；需要人工审核时在对话内弹窗审核。高级运行记录保留独立入口，`view=document` 保留独立文档视图。

已有任务通过 Bridge 接入对话，不调用模型、不重新启动任务、不更改审批。重复打开复用已持久化的关联对话；没有历史对话的任务创建一条带原始目标的系统上下文。项目和实验范围必须匹配，实验范围跟随原任务保存。复用已有对话时保留原始消息、运行中的处理状态和托管设置。

## 验证边界

浏览器工具无法验证管理员设置的访问策略，因而拒绝访问本地页面。本轮没有页面截图或浏览器交互验收，也没有通过其他浏览器操作方式绕过该限制。生产构建、接口验证和纯函数检查不能代替视觉及交互验收；审核窗口的实机打开、关闭和审批点击仍需浏览器访问恢复后检查。

此变更只整合研究产物与交互入口，不代表训练效果已经得到实验验证。
