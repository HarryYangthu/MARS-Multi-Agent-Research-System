# Product 与主干代码核对

本次同步将本地 Product 已有的研究记忆、基线匹配、调用预算、TensorBoard 图片归属、Windows 进程管理与离线启动代码纳入仓库，并保留自然语言仿真流程已有的修复。

## 核对范围

| 内容 | 核对方式 |
| --- | --- |
| 后端 `backend/app` | 运行目录与提交内容逐文件比较 SHA-256，包括提示词和 Schema |
| 前端 `frontend/src` | 运行目录、实际构建输入与提交内容逐文件比较 SHA-256 |
| 构建 | 类型检查、功能检查和独立的生产构建 |
| Windows | 原生启动脚本及独立 Windows CI，包含真实进程与离线安装检查 |
| 用户设置 | 保留本机模型连接、项目路径、执行命令和凭据；仓库提供可移植默认配置 |
| 研究记录 | 更新代码时保留对话、待审核产物和已有实验输出 |

带有 ` 2` 后缀的历史重复文件不作为 Python 模块加载，不纳入运行代码清单；不删除用户保留的这些副本。依赖目录、缓存和编译结果由锁文件与构建检查验证。

研究记忆核心实现在 `app.harness.research_memory`，存储层保留兼容导出；工具可直接使用核心实现。项目记忆页面对应的 API 在主服务注册。新增验证使用真实临时文件、SQLite、子进程和 ASGI 请求。

## 配置与发布

`configs/execution.yaml` 中的项目命令、解释器和数据绑定由各安装实例配置。仓库不写入开发者的代码、数据绝对路径或模型密钥。现有实例继续使用自己的运行工作区，代码升级不替换其设置。

Windows 离线工作流按依赖锁文件缓存依赖；缓存缺失时重新构建，不依赖某一次历史运行留下的临时下载链接。产品包不预置个人研究项目，公开合成项目继续留在源码仓库用于回归验证。
