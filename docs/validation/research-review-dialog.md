# 研究方案审核弹窗

验证日期：2026-10-01。

在研究对话中，关联任务进入待审核状态、最新方案成功读取后，自动打开审核弹窗。窗口展示真实方案正文，以及产物中已有的方法、参数边界、实验对照、论文来源和待确认事项。

- 同一任务、阶段尝试和文档内容只自动提示一次；状态轮询不会再次打断已关闭弹窗的用户。
- “稍后审核”及 Esc 可关闭窗口，页面保留“审核方案”入口。新阶段、新文档或修改后的正文可再次触发提示。
- “提出修改”显示意见输入，空意见不能提交；“批准并继续”调用已有审核接口。
- 审核组件与任务详情共用。提交前重新读取任务状态、最新文档版本和正文，拒绝旧文档、只读任务、无效格式和重复提交。
- 弹窗使用原生模态对话框，打开后焦点落在标题，背景不能交互；内容可滚动，审核操作保持可见。提交过程中禁止关闭。

- TypeScript 全项目检查通过。
