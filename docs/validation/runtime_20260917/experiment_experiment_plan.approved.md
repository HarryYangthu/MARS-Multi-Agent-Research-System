# Experiment Plan: CPU Polynomial Ridge Regression Fixture

## 1. Objective

Test whether changing `candidate.py` from the immutable baseline `DEGREE=1, REGULARIZATION=0.01` to `DEGREE=2, REGULARIZATION=0.0` lowers disjoint held-out MSE on the packaged synthetic numeric fixture.

- This is an engineering regression fixture only. It is not PIMC data and not a scientific novelty claim.
- Only `candidate.py` `DEGREE` and `REGULARIZATION` may change.
- Preserve `baseline/`, `data/`, `.mars/`, `diagnostics.yaml`, the evaluator, and the train/held-out split.
- Run exactly one experiment with seed 0: the same eight training samples and the same three held-out samples are used for both models; input normalization uses training samples only.

## 2. Hypothesis under test

The upstream proposal claims the fixture is exactly generated by `y = 1.5*x^2 - 0.75*x + 0.5` with no noise. The baseline linear model cannot represent the quadratic term, so it should have non-zero held-out MSE. Candidate `DEGREE=2, REGULARIZATION=0.0` should recover the quadratic polynomial on eight training points and lower held-out MSE to near machine precision.

Primary decision criterion:

- `improvement = baseline_mse - candidate_mse`
- Success: `improvement > 0` (`candidate_mse < baseline_mse`)
- Failure: `improvement <= 0`, validation failure, or inability to execute the configured real local command; report the actual comparison honestly.

## 3. Variables

### Independent variables

- `DEGREE`: integer polynomial degree; candidate value `2`.
- `REGULARIZATION`: finite ridge penalty >= 0; candidate value `0.0`.

### Controlled variables

- `seed`: fixed at `0`.
- `train/holdout split`: fixed 8 training / 3 held-out samples, no overlap.
- `training-only normalization`: fixed; normalization statistics computed only from training samples.
- Data file and baseline model code remain unchanged.

### Dependent metrics emitted by the evaluator

- `baseline_mse`: held-out validation MSE for `DEGREE=1, REGULARIZATION=0.01`.
- `candidate_mse`: held-out validation MSE for `DEGREE=2, REGULARIZATION=0.0`.
- `improvement`: `baseline_mse - candidate_mse`.
- `candidate_terms`: number of fitted coefficients; expected `3` for intercept + x + x^2.
