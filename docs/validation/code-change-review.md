- 成功写入：结合工具回执、回滚快照及内容哈希生成前后差异。
- 未成功写入：保留已记录的补丁或拟写入文本；没有修改前快照时不编造增删统计。

- 外部路径、损坏记录和过大文件不会进入预览。数量、读取大小和预览行数由 `configs/code_review.yaml` 控制。
