# 编码批准恢复验证

## 问题与改动

编码 Agent 已通过受控工具把代码写入任务 Git 分支。旧批准接口仍无条件应用 `patch.v1.diff`，且没有绑定任务分支能力，导致被项目基线只读规则拒绝。页面将明确的 HTTP 409 拒绝误判为未知提交结果，锁住按钮；文档轮询还会清除错误提示。

批准接口现在重新绑定原任务分支，先依据成功写入记录、回滚快照和当前文件核验净改动。文件路径及变更类型必须与编码方案一致，无法核验或部分实现均拒绝批准。已实现的代码不重复应用旧补丁；仅有补丁的实现仍通过 ToolRegistry 与 Gate 5 写入，并在批准前再次核验。

页面保留审核错误。明确的拒绝恢复按钮，网络中断、服务器错误或无法解析的响应保持待核对状态，提供查看任务状态入口，不自动重复提交。批准、修改意见提交使用现有配置中的请求时限。成功批准后，即使页面刷新失败，也不会将已经保存的决定误报为提交失败。
