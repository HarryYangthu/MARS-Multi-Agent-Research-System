## 证据与边界

- 验收使用已有完整研究的真实记录，六项本地作业回执、指标与原始文件内容保持不变。
- 历史请求未保存适配器最终正文时明确标为调用前快照；不补造未保存的请求。新增请求记录不包含认证头、API Key 或模型私有推理。
- 远端 GPU 的本机配置检查不会发起 SSH；真实服务器上的连通性、资源、数据与仿真仍须执行前核验。本轮未连接或运行远端 GPU。
- 导出按钮、产物 schema 合规、流程完成和统计显著性是不同验收层，不能互相替代。
- 实机检查不创建新科学任务、不替用户批准方案、不重跑实验。
- 发布验证从所选源码的 Git tree 建立干净目录，避免依赖其他未提交的本机文件。已有无关工作与凭据文件不进入本次提交。
