0. 摘要

本报告检验唯一目标：在载波分辨 PP 族基中加入带外镜像族 [[0,2],[1,-1]]（2c0−c1）及其频移 −162.494 MHz 后，单频 group1 case17 的对消改善是否发生净变化。自变量仅为 ca_terms 项数（2 项 → 3 项），其余条件（数据、seed、预算、模型、build_L1C:false、share_L30_across_terms:true 等）逐字保持一致。

结论：本轮四臂（A 基线重跑 / B ca_pp_2term / C ca_pp_3term / D ca_k1_control）全部 status=completed，failures=0（execution/batch_summary.json）。处理臂 C improvement_db = 17.20984，相对对照臂 B 的 17.18968 净差值 +0.02016 dB（≥0），相对本轮同快照基线 A 的 17.17516 高出 +0.03468 dB；参数量实数等效量 4704（= 基线 6784 的 69.3% ≤ 80% 门限 5427.2）。因此在本轮同快照口径下 C 同时满足「参数量 ≤ 5427.2」与「improvement_db ≥ 合同门限 17.175」两项达标条件。

必须同时声明的限制：本结论基于单 seed（42）单数据集（singleband_g1_c17）单 case（case17）单次运行，净差值幅度（+0.02 dB 量级）与最大残差指标（C 的 maxRES 反而高于 B 约 +0.357 dB）之间存在方向不一致，不能外推为「带外镜像族普适有效」的结论，只能登记为「在本次设置下未观察到劣化且均值判据略优」的待验证假设。

项目研究多通道基站无源互调（PIM）对消：由已知 TX 基带 IQ 预测落入 RX 带的 PIM 并减去（见项目 README.md）。本地单频参考场景的 TX 实为双载波（载波带宽 5/10 MHz，位于下行带内），因此即使在「单频段」语义下也存在载波间互调 2c1−c0、2c0−c1 等族基项。PP（物理先验）用于显式注入互调项的射频中心与相对 RX 的频移，把幅度非线性交给 LUT，把频率位置交给固定相位搬移（README.md 第 6 节）。
