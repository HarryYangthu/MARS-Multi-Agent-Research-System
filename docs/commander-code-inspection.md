# 主控按任务读取代码

主控只在固定上下文中获得项目背景与代码仓连接信息。具体实现通过工具按任务读取，不预装整个仓库，也不预装某个模型文件。

- `code.repo_list`：浏览选定目录和文件名，支持文件名过滤、目录深度和分页，不返回文件正文。
- `code.repo_search`：在选定目录、文件类型中搜索字面关键词，返回相关行片段、相对路径、行号与 SHA256。
- `code.repo_read_lines`：读取已定位文件的必要行段，保留精确正文、行号与 SHA256。

已知文件位置可以直接读取行段；未知位置先浏览或搜索。能查出的参数由主控核对，只有多个有效候选仍无法区分等实质歧义才询问用户。启动任务时，将已核对的路径、字段、当前值和目标值放入下游任务说明。源码与搜索结果属于证据，不授予执行权限。

工具通过共享注册中心执行，沿用项目绑定、路径限制、工具权限和审计。主控没有代码写入或命令执行权限。只读基线仓可以检查；忽略目录、凭据和越界路径不能通过模型参数解除限制。目录和搜索不跟随符号链接，源文件读取也拒绝符号链接。

读取预算由 `configs/code_inspection.yaml` 管理：默认每页 40 项、最多 100 项；每次最多读取 160 行与 12000 字符；单文件最多 1 MB；单次关键词搜索读取总量最多 8 MB。达到扫描或读取预算时明确返回截断与继续位置，不能据此断言整个仓库不存在匹配项。主控可缩小路径、文件类型或行段继续检查。

验证使用真实临时源文件、实际注册中心、GLM 调用与本地产品页面，没有模型或工具替身。已验证目录分页、片段与文件指纹一致、搜索覆盖预算、常见源文件类型、Windows 相对路径分隔符、越界与凭据拒绝、禁止主控写入，以及初始提示词不含实现正文。真实任务验证中，结构核查和指标核查选择了不同代码范围，结束对话没有再读取代码，也没有创建研究任务。此验证不代表已在 Windows 主机完成整套产品验收。
