# 按目标持续研究与进化

在研究对话中给出性能目标、资源约束和预算，开启主控托管。例如：

> 优化五层模型的学习率。每组完整训练 2 个 epoch，固定 seed=2026。
> 候选 RES 比同轮基线降低至少 0.5 dB，参数不能增加。
> 最多仿真 5 轮，连续 3 轮不改善时停止；达标后保持代码不变复验两次。
> 保留 TensorBoard、逐轮对比和报告。

已有模型运行和明确改参仍走快捷编码与执行。持续研究使用 `run.auto_research`，不会把每一次普通仿真都扩展为调研。

## 实际执行过程

1. 主控读取真实配置和入口，固定本任务的目标、约束、评价协议、修改范围和预算。
2. Idea 读取项目背景、代码、相关历史实验并开展针对性调研。原始阅读和研究审查保留在原有审计链路中。
3. 将研究与代码上下文归档，进行多次独立候选推理、逐候选独立审查和两两比较。代码计算 Elo，确定优先验证方案。可指定多个系统级模型配置；每次推理使用独立会话。
4. 交接机制假设、支持与反对证据、可改模块、冻结部分、预期观测、否定条件及停止条件。原始方案和选优记录一同保留。
5. 实验设计和 Coding 使用既有运行引擎、审批、独立实验分支和受治理的文件工具。每轮实际执行匹配基线和候选。
6. 从已完成作业及其校验过的证据计算差距。未达标则交给 Coding；连续未改善则返回 Idea 重新研究。实验设计的反馈链也经过 Coding，避免执行旧配置。
7. 首次达标先保持代码不变重复执行。所有指标与约束复验通过才记为 `goal_met`。预算结束和研究停滞分别记录，不会改写为目标达成。

人工审批模式保留逐阶段审批；每轮结果确认后可选择“批准并继续进化”。主控托管模式在既定目标和范围内推进。停止按钮与正常恢复流程继续有效。

实验清单只描述本轮实际运行的基线与候选。后续参数由本轮测量决定，不能把“下一轮待定参数”写成将立即执行的作业。交接不兼容时先修正清单，保留已有研究与失败原因，再继续编码。

## 六个模块

| 模块 | 标识 | 可以研究的内容 |
| --- | --- | --- |
| 前向模型 | `forward` | FIR、通道混合、LUT、连接和结构参数 |
| 损失函数 | `loss` | 误差处理与训练目标 |
| 梯度与反传 | `backward` | 梯度路径、算子反传与梯度处理 |
| 优化器更新 | `optimizer` | 更新规则及优化器状态 |
| 训练策略 | `training_strategy` | 初始化、批次、预算、调度、验证和检查点 |
| 数值与算子实现 | `numerics` | 跨前向、反传和更新的数值表示与算子 |

模块定位可以细化为 Python 函数/类方法或 YAML 字段。受保护代码与评价口径继续冻结；外层研究改变代码与任务上下文，内层训练更新被研究模型的参数，不更新 LLM 权重。`epoch` 与优化器更新数保持不同的单位。既有 RMS 损失不会被命名习惯悄悄替换成 MSE。

## 结果与恢复

每个研究保留 `input/evolution_contract.v1.json`、`evolution/state.json`、选优和交接记录，以及逐轮 `code.json`、`metrics.json`、`diagnostics.json`、`evidence_card.json`。界面显示当前研究状态、最佳轮次、复验数量与逐指标差距。

对照组使用任务起点的独立冻结代码。候选修改共享模型文件时，对照组也不会跟着变化。有效性检查要求真实完成作业、指标与实际收据一致、证据哈希完整。

支持的项目输出会提供真实更新曲线、各通道表现、最佳与最终检查点，以及检查点系数的范数和明确矩阵定义下的奇异值/秩。未提供的诊断保留缺失说明，完整频谱和模型函数行为等分析需要对应项目提供可计算的原始观测。

模型调用和选优阶段完成结果可复用；崩溃后不会重新执行已核验的训练。测量完成与追加下一轮之间也可恢复。未知写入或仍在运行的训练按现有恢复机制先核对实际状态。

模型服务恢复后，可点击对话底部的“一键继续”。它先读取最新状态，再继续最后一条未完成的用户请求；刷新页面后入口仍保留。已有研究任务的恢复卡片也提供“一键继续”，优先使用可用检查点，没有检查点时重试失败阶段。研究已完成后的问答中断只恢复该问题，不重启研究。重复点击或旧页面提交会核对原请求与状态，已完成的请求不再显示继续入口。“重新读取对话”只更新页面状态。

审核材料按实际可用空间打包：保留完整目标、项目规则与当前产物字段；优先去除重复正文，再按完整段落缩减参考资料，并标明原文入口。后续阶段保留已批准的方法定义与执行协议，将之前审过的调研细节保存为带指纹的引用。重新推理使用结构化的近期测量与历史记录，避免长方案把后面的失败结果截掉。

普通仿真与进化任务的已完成结果都会写入项目实验记忆，入档收据可复用；索引暂不可用时保留待处理记录，不将已完成训练改为失败。进化上下文按任务检索历史配置、训练方式、结果与比较条件。原有全局基线选择不会被短预算筛选结果自动覆盖。最终报告引用最佳轮次与完整结果，筛选和正式训练仍保持各自的评价条件。
