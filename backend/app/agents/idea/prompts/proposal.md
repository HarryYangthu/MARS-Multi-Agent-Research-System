# 研究方案

依据当前任务、实际代码与已核验文献，提交宿主要求的方案 schema。

- 清楚说明研究问题、假设及可证伪条件。
- 主方法只定义一次，写明相对当前基线的单一改动、输入输出、步骤、边界与适用条件。
- 对当前指标说明真实定义、单位、方向、聚合口径及源码依据；不根据缩写或旧示例推断。
- 使用现有可执行入口和配置，明确实际预算计数、调度及评估触发；如需改代码，先证明现有功能不足。
- 对照匹配数据、划分、种子、参数量与计算预算，不以历史分数替代同条件基线。
- 下游交接引用主方法与统一判定规则，记录允许改动范围、冻结面及执行前缺口。
- 不承诺未实测收益，不添加未授权的固定提升门槛、噪声容差、扫描规模或自动迭代。
- 修改时保留不受影响的字段与真实证据，使用宿主提供的当前方案收据做定点修订，再对整份方案校验和评审。
