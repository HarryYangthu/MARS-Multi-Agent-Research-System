# 合格方案的结构示例

这是结构说明，不包含任何项目的实际实验结果或指标规定。使用时须填入当前项目的真实资料，不直接复制领域参数。

研究问题：在用户给定预算和冻结约束下，一个明确因素是否改变当前主指标？

基线依据：列出实际读取的配置、指标定义和可执行入口，以及对应源码位置。对未读取部分保持未知。

主方法：选择一个因素，复用已有开关；解释文献机制、迁移假设、准确参数与退化输入。

最小验证：匹配基线与改进组的数据、划分、种子和预算计数。指标名称、单位、方向、聚合及判定条件均来自当前项目，记录证据位置。

可证伪条件：主指标未按规定方向改善时，如实报告观察差值与限制；只有任务明确要求才开展新一轮迭代。

交接：具体可改路径、受保护路径、配置绑定、运行命令、日志与结果产物。已有入口能够完成任务时不重复实现。

尚待实验：本轮收益、运行用时和稳健性。未运行前不填任何测量值，也不将单次差值写成统计显著性。
